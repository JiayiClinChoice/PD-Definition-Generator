# PD Definition Generator Frontend

参考设计图的宽版项目列表与分步工作区，采用暖灰背景、白色卡片和中性灰表单。
蓝色仅用于主操作与选中状态，不使用蓝色页面背景或渐变。

## 启动

```powershell
cd Frontend
Copy-Item .env.example .env
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5173`。先启动后端（默认 `8001`）。
`VITE_API_BASE_URL` 默认为 `/api`，由 Vite 代理到后端。
生产环境也需配置同源 `/api` 反向代理；`npm run preview` 仅用于检查构建。

## 功能

- 注册、登录、会话恢复、退出与跨标签页账号同步；密码至少 3 位。
- 按账号隔离项目，支持新建、搜索、切换、重命名和删除。
- 登录后进入项目首页；可搜索项目名、方案编号或申办方。点击项目进入工作区，左上角返回列表。
- 工作区包含方案校验、PD 分类、方案事实抽取、字段协议、PD 定义生成五个步骤。
- 上传方案、显示验证状态、编辑方案元数据。
- PD 分类支持拖动排序、行尾悬停加号插入、删除与自动编号，不需要编辑 JSON。
- 字段规则使用可展开表单，支持拖动调整显示顺序（保存在当前浏览器）；后端字段标识、序号、标签和必填属性保持不变。
- 允许值和示例每行一条，规则修改会实际保存，不会重置默认值。
- 读取已保存的分类、字段、事实和定义；刷新或切换项目不会自动重新调用 AI。
- 事实与定义支持搜索、拖动排序、任意行下方插入、直接编辑、删除及保存；排序后自动更新位置序号。
- 事实卡片以两位序号展示，内容按文本自动增高；删除旁的勾选图标可确认或取消确认，点击保存后持久化。修改分类、内容或来源会取消该事实的确认，排序不影响确认状态。
- 定义使用可横向滚动的表格，仅展示字段协议中的列，不额外保留操作列；悬停按钮浮于当前可视行的右下角。列名及列顺序按字段协议，序号对应从 1 递增的 position；Excel 使用相同列名。
- AI 调整区使用适中大小的折叠箭头和聊天式圆形发送按钮；PD 分类、方案事实、字段协议及定义页提供回到顶部和到底部按钮。
- 定义表格随页面自然向下延伸，顶部表头和同步水平滚动条保持粘性定位，不显示底部滚动条。悬停或键盘聚焦行时，右下角显示新增、确认和删除图标；触屏始终显示。确认状态保存到后端，编辑内容会取消确认，排序不会；AI 修订保留未改变内容的用户确认。
- 拖动手柄支持鼠标、触摸；键盘可用空格选中、方向键移动、空格放下或 Escape 取消。触摸设备始终显示插入加号。
- AI 提取、生成和按要求修订为显式操作；进度在上传区域或结果主区域显示。
- 定义导出为真正的 Excel（.xlsx），支持中文、换行、冻结表头、筛选和自动换行；文本始终作为字符串写入，不会执行公式。
- Excel 库在导出时按需加载，不增加初始页面的加载体积。
- 站内提示、切换/退出/刷新及删除确认统一使用应用内弹窗，支持键盘、Escape 取消和焦点恢复；删除整个项目必须输入完全一致的项目名称。
- 浏览器刷新、关闭标签页时的未保存修改/后台任务保护使用浏览器自身的离页提示，此类系统提示受浏览器限制，无法替换为网页内弹窗。

## 数据与行为

每个账号管理自己的独立项目，本轮不包含共享项目或成员角色。
后端使用 HttpOnly Cookie 会话；不在 localStorage 保存密码或令牌。
原 `VITE_USER_KEY` / `X-User-Id` 冒用身份机制已移除。

保存分类会清空事实，在有事实时弹窗要求确认；已有定义保留，
需人工核对。字段标识和必填属性由后端输出结构固定，允许编辑含义、
允许值、生成要求和示例，不支持新增任意输出字段。AI 运行期间仅锁定当前项目编辑；
可返回列表继续操作其他项目，各项目任务、进度、错误和结果独立保留。
当前页面会保留运行中的项目工作区，任务完成后返回该项目即可查看结果；
浏览器刷新、关闭或账号退出会结束页面内的任务追踪（后端已保存的数据仍可重新加载）。失败保留已有结果。
每个项目关联一份方案，更换方案请新建项目。

## Excel 格式

仅导出一个“PD 定义”工作表。协议字段后附加“方案版本”列，取自已经保存的方案版本与版本日期，
格式为 `Vx.x / YYYY-MM-DD`；版本或日期缺失、格式无效时，提示先完善方案信息，不导出虚假版本。
版本列从首条数据到最后一条数据合并（不包含表头）。保持当前定义顺序，连续相同的分类、标准各自合并；
不跨越其他内容合并非相邻单元格，避免吞掉中间数据。所有单元格左对齐、顶端对齐并自动换行。
中文及中文标点使用微软雅黑，拉丁字母、数字使用 Times New Roman；混合文本按字符段设置字体。
表头、正文、混合文本均为 10 pt，表头加粗；没有额外工作表。

## 验证

```powershell
npm run build
npm run test:e2e
```

Playwright 在独立的 `5175` 端口启动当前工程，避免误用正在运行的其他开发服务。
使用本机 Chrome，覆盖桌面、手机、平板和横屏。未安装 Chrome 时
可调整 `playwright.config.ts` 的浏览器 channel 并安装相应浏览器。
浏览器回归测试模拟 API，验证账号切换、表单持久化、项目切换、错误恢复、
拖动排序、行间插入、跨项目并行操作、上传进度定位及 Excel 文件内容；真实服务的隔离、事务和 AI 流程由后端测试验证。
